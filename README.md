# Radar SP · Investimento imobiliário

Relatório interativo de bairros de São Paulo, com base na planilha `dados_imoveis_SP_Aula.xlsx`.

## Análise

- Somente imóveis com área superior a 40 m².
- 2.038 registros após a remoção de linhas idênticas, em 89 bairros.
- Pesos: preço/m² 30%, distância do metrô 25%, amenidades 20%, IDH 15% e renda 10%.
- Metodologia, fontes e limitações descritas na própria página.
- Base analisada em setembro de 2026; a data de coleta original não foi informada.

## Executar

Abra `index.html` em um navegador. Não há dependências ou etapa de compilação.

## GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, branch main e pasta / (root).

O ranking mede atratividade relativa e não estima rentabilidade ou probabilidade de locação.
